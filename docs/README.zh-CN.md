# Iris · 专注论文阅读

[English](../README.md) · [下载最新版本](https://github.com/zbhou2002/iris-zotero/releases/latest)

Iris 是基于 AIdea 修改的 Zotero 阅读助手：结合当前论文对话、手动划词翻译、精华高亮，以及可选的本地语音输入。

## 安装与更新

下载 Releases 中的 `Iris-<版本>.xpi`，在 Zotero 的“工具 → 插件（或附加组件）→ 齿轮 → 从文件安装”中选中它，然后重启 Zotero。

已有 AIdea 或旧 Iris 的用户直接覆盖安装，不要先卸载。两者沿用相同插件 ID，不能同时安装。升级前建议备份 Zotero 配置。首次正式安装后，新版会通过 Zotero 的插件更新机制提供；仍需要 Zotero 开启更新且能够访问 GitHub。

## 语言

设置 → 界面语言：跟随系统、English、简体中文。默认跟随系统；不支持的系统语言回退到英文。选择后立即生效，无需重启，不改变翻译目标语言、未发送草稿或已有聊天内容。

## 使用边界

打开 Iris 后，在 PDF 中划选文段，输入框上方会出现一个靠左的小型“引用文段”标签，悬停可查看论文名，输入区域不显示文段正文。输入问题并发送，模型会以引用文段为重点，同时保留论文全文作为背景上下文。重新划选会替换尚未发送的引用，点击 × 可移除；关闭 PDF 选文弹框不会清除引用。划选本身不会调用模型。发送后引用随该轮对话保存。

对话、翻译和高亮使用你选择的模型服务，会向服务商发送相关文本。本地语音识别不需要转写 API Key，但首次需要联网下载运行环境和模型；识别完成后若发送为聊天，文字仍会发送给选定模型。首次下载、模型加载和推理均可能需要等待。

打开输入面板及每次录音前，会检查本地语音文件。未安装或文件不完整时，麦克风有描边提示，点击开始安装；安装中变灰禁用，仍可打字和聊天。输入框内显示安装阶段及已用时间；模型下载显示实际完成量，总大小已知时显示百分比（包含续传部分，不按时间估算）。验证完成后才恢复麦克风，需要再点一次才录音，不会下载完自动开始。失败后显示原因，可点击重试。多个面板共享一次安装，切换设置或收起侧栏不会重复下载。自动安装有 30 分钟超时，网络较慢或中断时可能需要重试。

精华高亮没有固定句数配额，筛选提示词可以在设置中修改。高亮是阅读辅助，不能保证客观或完整；没有可用文本的扫描 PDF 可能需要先 OCR。

安装包声明兼容 Zotero 7–9，实际运行测试环境为 Windows / Zotero 9.0.6。macOS 安装及语音脚本尚未完成实机验证。Linux 暂无自动语音环境安装。
